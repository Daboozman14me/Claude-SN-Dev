# Meeting Room Booking — objectives

Staff need to book meeting rooms for a time slot.
The system must stop two bookings overlapping for the same room.
Rooms have a capacity, and a booking must not exceed it.
Requesters get an email when a booking is confirmed or cancelled.
Only facilities admins can add or retire rooms.
